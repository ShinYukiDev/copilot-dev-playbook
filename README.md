# copilot-dev-playbook

## 概要

本リポジトリは、GitHub Copilot を活用して、保守・運用担当者が実務で成果を出すための
**導入・学習・実践・改善のナレッジ集**です。

日常の作業や教育にそのまま使えるテンプレートと運用ガイドを提供し、
開発生産性の向上と品質安定化を支援します。

## 目的

- 開発生産性の向上
- コード品質の標準化
- ナレッジの蓄積と再利用
- 新人教育の効率化

## 対象者

- 保守・運用担当者

## フォルダ構成

```text
01_onboarding/
├ vscode_setup.md
└ copilot_setup.md

02_training/
├ vscode_training/
├ copilot_training/
└ git_github_training/

03_practice/
├ prompt_templates/
└ instruction_templates/

04_best_practices/
├ coding_patterns.md
└ prompt_patterns.md
```

## 学習フロー（最重要）

1. `01_onboarding` を読む（環境構築）
2. `02_training` で基礎を学ぶ
3. `03_practice` を使って実務で活用する
4. `04_best_practices` を参照し改善する

👉 この順番で進めれば、最短で実務投入できます。

---

## 使い方

### 1. はじめて利用する場合

- `01_onboarding` を必ず実施
- VS Code + GitHub Copilot をセットアップ

### 2. 学習する場合

- `02_training` の各資料を順番に実施
- ハンズオン形式で理解を深める

### 3. 実務で使う場合

- `03_practice/prompt_templates` を活用
- 必要に応じてカスタマイズ

### 4. 改善する場合

- `04_best_practices` を参照
- 良いパターンを横展開

## 運用ルール

- 変更は Pull Request ベースで管理
- テンプレートは再利用前提で作成
- 不要なファイルは削除せず改善
- ベストプラクティスは随時更新

## 最後に

このリポジトリは「読むもの」ではなく  
**使って改善し続けるもの**です。

積極的に使い、ナレッジを蓄積してください。
