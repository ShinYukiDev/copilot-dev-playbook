# log-analyzer

このskillは、APログおよびLBログを分析し、障害の傾向、原因、対策をレポートとしてまとめます。

## 入力情報

- APログファイル（例：app.log）
- LBログファイル（例：lb-access.log）

## 実行手順

1. 指定されたログを分析
2. 原因を仮説立て
3. 対策を検討
4. レポート作成

## 出力情報

マークダウン形式でファイル出力。

- 障害の概要（日時、影響範囲）
- 原因（仮設）
- 対策（暫定・恒久）
